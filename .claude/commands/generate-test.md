# Generate a Playwright Test

Generate a test from the user's requirement.

1. Inspect relevant existing tests, Page Objects, locator JSON, fixtures, and configuration.
2. Identify reusable framework components before writing code.
3. Produce business-readable pytest/Allure steps.
4. Reuse PageRepository/Page Objects and locator names.
5. Add only missing framework artifacts that are genuinely required.
6. Validate imports and run the focused test if the environment permits.
7. Summarize the requirement-to-test mapping.
