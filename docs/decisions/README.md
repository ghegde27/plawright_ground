# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the Playwright automation framework.

ADRs document important engineering decisions and, most importantly, the reasoning behind those decisions.

## When to Create an ADR
Create an ADR when a decision affects architecture, scalability, test isolation, parallel execution, authentication, configuration, reporting, maintainability, technology selection, or migration strategy.

## ADR Lifecycle
```text
Proposed
   ↓
Discussed
   ↓
Accepted / Rejected
   ↓
Implemented
   ↓
Superseded (if replaced)
```

## Source of Truth
The Git repository is the authoritative source of truth for architectural decisions. AI conversations may help create or review decisions, but the final decision must be recorded in Git.
